Como ler um atalho

Um + significa "segure as teclas anteriores e aperte a próxima". As teclas são apertadas na ordem da esquerda para a direita, e as primeiras ficam seguradas.

Ctrl
Segure o Control primeiro…
Shift
…depois segure também o Shift…
C
…e aperte C. Solte tudo. Resultado: copia o texto selecionado no terminal.

Há dois outros formatos. Ctrl+B D (tmux) quer dizer "aperte Ctrl+B, solte, depois aperte D". Já ^X (nano) é outra forma de escrever Ctrl+X.

Por que Ctrl+C não copia no terminal?

No terminal, Ctrl+C é o sinal de cancelar o comando que está rodando, um costume com décadas de idade. Para copiar e colar, use Ctrl+Shift+C e Ctrl+Shift+V.

Histórico: !! e !$

Não são atalhos de tecla, mas economizam tanto quanto um. O bash troca essas marcas por partes do comando anterior antes de executar, e mostra na tela como ficou.

MarcaÉ trocada porUso típico
!!O comando anterior inteirosudo !! quando esqueceu o sudo
!$O último argumento do comando anteriormkdir projeto e depois cd !$
!textoO último comando que começa com "texto"!ssh repete o último ssh
$ apt install htop
Erro: Não foi possível abrir arquivo de trava /var/lib/dpkg/lock-frontend - open (13: Permissão negada)
Erro: Não é possível adquirir a trava da interface do dpkg (/var/lib/dpkg/lock-frontend), você é root?
$ sudo !!
sudo apt install htop                       « o bash mostra o comando já trocado
[sudo: authenticate] Senha:
$ mkdir relatorios-2026
$ cd !$
cd relatorios-2026
Cuidado com ! dentro de aspas duplas

echo "Oi!" funciona, mas echo "Oi!ls" tenta buscar um comando. Para textos com !, use aspas simples: echo 'Oi!'.

Emergência: TTY e SysRq

Quando a interface gráfica trava, o teclado ainda pode salvar você. Use os atalhos na ordem, do mais leve ao mais pesado. O passo a passo completo está em Quando o Sistema Trava.

AtalhoO que fazQuando usar
Ctrl+Alt+F3 … F6Abre um terminal de texto (TTY) fora da interface gráfica. Entre com usuário e senhaA interface travou, mas o computador ainda responde
Ctrl+Alt+F1Tela de login gráficaVoltar ao login
Ctrl+Alt+F2Volta para a sua sessão gráficaDepois de resolver no TTY
Alt+SysRq+S, U, BGrava os discos, remonta só-leitura e reiniciaNem o TTY responde
Botão de energia por 5–10 sDesliga à forçaÚltimo recurso: pode perder dados

As teclas mágicas: REISUB

SysRq é a mesma tecla do Print Screen; em notebooks, às vezes precisa de Fn. Segure Alt+SysRq e aperte as letras devagar, uma por vez, com 1 a 2 segundos entre elas.

LetraO que fazFunciona no padrão do Ubuntu?
RTira o teclado do controle da interface gráficaNão
EPede a todos os processos para terminar (SIGTERM)Não
IMata todos os processos na hora (SIGKILL)Não
SGrava nos discos o que estava pendente (sync)Sim
URemonta os discos como só-leituraSim
BReinicia imediatamenteSim

Por que só S, U e B? O Ubuntu vem com kernel.sysrq = 176, que é 16 (sync) + 32 (remontar) + 128 (reiniciar). As outras letras ficam bloqueadas:

$ cat /proc/sys/kernel/sysrq
176                                          « 16 + 32 + 128: só S, U e B
$ cat /usr/lib/sysctl.d/55-magic-sysrq.conf | grep -v '^#'
kernel.sysrq = 176

A aula Quando o Sistema Trava mostra como liberar todas as letras com kernel.sysrq = 1, e quando isso vale a pena.

Numa máquina virtual

O computador hospedeiro "pega" esses atalhos antes da VM. No VirtualBox, use a tecla Host (normalmente Ctrl direito) + F3, ou o menu Entrada → Teclado.

Resumo

  • No terminal, copiar e colar levam Shift: Ctrl+Shift+C / V. Ctrl+C cancela.
  • Tab, ↑ e Ctrl+R poupam a maior parte da digitação.
  • sudo !! repete o último comando como administrador.
  • Travou tudo: Ctrl+Alt+F3 primeiro. Se nem isso responder, Alt+SysRq + S U B.
  • Preso no vim: Esc, :q!, Enter.
