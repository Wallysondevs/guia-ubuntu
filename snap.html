Ubuntu Snap

Além dos pacotes do apt, o Ubuntu usa snaps: programas empacotados com tudo de que precisam, que se atualizam sozinhos. O Firefox e o Chromium do Ubuntu, por exemplo, são snaps. Nesta aula você vai entender como eles funcionam e como instalar, atualizar, voltar versões e remover.

Você vai aprender
  • O que é um snap e em que ele é diferente de um pacote do apt.
  • Como achar, instalar e remover snaps.
  • O que são canais, revisões e o modo --classic.
  • Como voltar para a versão anterior quando uma atualização dá problema.
  • Por que um snap às vezes "não enxerga" uma pasta ou um pendrive.

O que é um snap

Um pacote do apt usa bibliotecas que já estão no sistema e são compartilhadas com outros programas. Um snap traz dentro dele quase tudo de que precisa. Isso tem consequências:

  • Funciona igual em várias versões do Ubuntu, e o desenvolvedor publica direto, sem esperar o Ubuntu.
  • Atualiza sozinho, várias vezes por dia se houver versão nova.
  • Roda numa "caixa" isolada (sandbox): só acessa o que tem permissão, como a sua pasta pessoal.
  • Ocupa mais espaço e costuma abrir um pouco mais devagar na primeira vez.

Os snaps instalados ficam em /snap/. Por isso o processo do Chromium aparece como /snap/chromium/3554/…/chrome no ps: 3554 é o número da revisão instalada.

Achar e instalar

Procurar: snap find

$ snap find htop
Name      Version   Publisher     Notes  Summary

O ✪ marca um editor de destaque; sem símbolo, é um editor comum. Prefira snaps de editores verificados (✓) ou do próprio projeto.

Instalar: snap install

sudo
Instalar mexe no sistema.
snap install
Baixa e instala o snap.
vlc
O nome do snap (o reprodutor de vídeo VLC).
$ sudo snap install vlc
vlc 3.0.21 from VideoLAN✓ installed

Enquanto baixa, aparece uma barra de progresso. No fim fica só essa linha: nome, versão, quem publicou e "installed" (instalado). O VLC já aparece no menu de aplicativos e pode ser aberto pelo terminal com vlc.

Modo clássico: --classic

Alguns programas, como editores de código, precisam acessar o sistema todo e não funcionam isolados. Eles usam o modo classic, e você precisa concordar explicitamente:

$ sudo snap install code
error: This revision of snap "code" was published using classic confinement and thus may perform
       arbitrary system changes outside of the security sandbox that snaps are usually confined to,
       which may put your system at risk.

       If you understand and want to proceed repeat the command including --classic.
$ sudo snap install code --classic
code 1.105.0 from Visual Studio Code (vscode✓) installed

A mensagem diz: "este snap usa confinamento clássico e pode fazer mudanças fora da caixa de segurança; se você entende, repita com --classic". Só faça isso com programas de fontes confiáveis.

Canais: escolher entre estável e teste

Cada snap pode ter quatro canais, do mais seguro ao mais experimental:

CanalPara quem
stableTodo mundo. É o padrão.
candidateQuem quer testar a próxima versão estável.
betaTestadores.
edgeDesenvolvedores: a versão do dia, pode quebrar.
$ sudo snap install firefox --channel=beta
$ sudo snap refresh firefox --channel=stable

Atualizar, voltar e segurar

Os snaps se atualizam sozinhos, em segundo plano. Você pode forçar ou consultar:

$ snap refresh --list
Name      Version        Rev   Size   Publisher    Notes
chromium  155.0.8059.79  3559  194MB  canonical✓   -
$ sudo snap refresh
chromium 155.0.8059.79 from Canonical✓ refreshed

snap refresh --list mostra o que tem versão nova; sudo snap refresh atualiza tudo; sudo snap refresh chromium atualiza só um.

"Fechar o app para atualizar"

Se o programa estiver aberto, o snap espera ele fechar para trocar a versão, e o Ubuntu mostra uma notificação pedindo para fechá-lo. Feche e abra de novo.

Voltar para a versão anterior: snap revert

O snap guarda a revisão anterior. Se uma atualização quebrou algo, volte em segundos:

$ sudo snap revert firefox
firefox reverted to 143.0.4-1
$ snap list --all firefox
Name     Version     Rev   Tracking       Publisher   Notes
firefox  143.0.4-1   7085  latest/stable  mozilla✓    -
firefox  144.0.2-1   7120  latest/stable  mozilla✓    disabled     « a versão nova fica guardada, desativada

Segurar as atualizações

$ sudo snap refresh --hold firefox
$ sudo snap refresh --unhold firefox

--hold pausa as atualizações automáticas daquele snap (sem prazo, se você não informar um); --unhold libera.

Remover

$ sudo snap remove vlc
vlc removed

O snap guarda uma cópia dos dados do app por 31 dias (um "snapshot"), caso você mude de ideia. Para remover sem guardar nada, use sudo snap remove --purge vlc.

Permissões: as "interfaces"

Como o snap vive numa caixa isolada, cada acesso (câmera, microfone, pendrives, rede) é uma interface que precisa estar conectada:

$ snap connections chromium
Interface          Plug                         Slot              Notes
audio-playback     chromium:audio-playback      :audio-playback   -
audio-record       chromium:audio-record        :audio-record     -
camera             chromium:camera              :camera           -
home               chromium:home                :home             -
removable-media    chromium:removable-media     -                 -       « não conectada

Uma linha com - na coluna Slot é uma permissão desconectada. Nesse exemplo, o Chromium não enxerga pendrives. Para liberar:

sudo snap connect
Conecta uma interface…
chromium:removable-media
…do snap chromium, a permissão removable-media (pendrives e HDs externos em /media).
$ sudo snap connect chromium:removable-media

Na interface gráfica, o mesmo ajuste fica em Configurações → Aplicativos, escolhendo o app.

Evite instalar o mesmo programa pelos dois caminhos: você fica com dois ícones e não sabe qual está abrindo. Veja também Flatpak.

Os comandos do snap não rodam no terminal simulado deste guia. Pratique numa máquina virtual.

Quando não funciona

"snap … not found" 
$ sudo snap install vscode
error: snap "vscode" not found

O que aconteceu: o nome do snap é outro. O VS Code se chama code.

Como resolver: procure com snap find "visual studio code" e use a coluna Name.

"access denied" 
$ snap install htop
error: access denied (try with sudo)

O que aconteceu: faltou o sudo (em algumas situações, o Ubuntu pede a senha numa janela em vez de dar o erro).

Como resolver: sudo !!.

O app não abre arquivos de uma pasta

O que aconteceu: a interface home dá acesso à sua pasta pessoal, mas não às pastas ocultas (que começam com ponto), nem a /mnt ou a outros discos.

Como resolver: mova o arquivo para uma pasta comum (como Documentos) ou conecte a interface certa, como removable-media.

Disco cheio de revisões antigas

O que aconteceu: o snap guarda revisões antigas de cada app. Veja com snap list --all: as marcadas como disabled são cópias antigas.

Como resolver: remova uma revisão específica com sudo snap remove nome --revision=NÚMERO, ou reduza quantas são guardadas: sudo snap set system refresh.retain=2.

Resumo

  • Snaps trazem as próprias dependências, rodam isolados e se atualizam sozinhos.
  • snap find → snap info → sudo snap install; --classic só para apps confiáveis que pedem.
  • sudo snap revert desfaz uma atualização problemática em segundos.
  • App sem acesso a algo? Veja snap connections e conecte a interface.
  • Ferramentas de sistema: prefira o apt. Apps de desktop: snap ou flatpak.
