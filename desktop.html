Ubuntu O Desktop

O desktop ("área de trabalho") é a parte gráfica do Ubuntu: janelas, ícones, menus e a barra lateral. O Ubuntu usa o ambiente GNOME, com alguns ajustes próprios. Nesta aula você aprende a se mover nele sem mouse e a ligar o mundo gráfico ao terminal.

Você vai aprender
  • O nome e a função de cada parte da tela.
  • Abrir qualquer coisa em segundos com a tecla Super.
  • Instalar programas pela Central de Aplicativos.
  • Usar o gerenciador de arquivos com atalhos.
  • Abrir pastas e arquivos do terminal na interface, e o terminal a partir de uma pasta.
Usa Ubuntu Server, Multipass ou WSL?

Eles não têm desktop. Você pode pular para O Terminal.

O terminal também sabe qual desktop está rodando. O echo mostra o valor de uma variável, uma informação guardada pelo sistema (você vê mais em Primeiros Comandos):

echo
Mostra na tela o que recebeu.
$XDG_CURRENT_DESKTOP
Uma variável. O $ na frente pede o valor dela.
$ echo $XDG_CURRENT_DESKTOP
ubuntu:GNOME                                     « GNOME com os ajustes do Ubuntu
$ echo $XDG_SESSION_TYPE
wayland                                          « o sistema gráfico em uso
$ gnome-shell --version
GNOME Shell 50.1

Wayland é o sistema que desenha as janelas na tela. Ele substituiu o antigo X11 (ou Xorg). Você só precisa saber disso quando um programa antigo, de captura de tela ou de acesso remoto, não funciona direito.

Abrir qualquer coisa: a tecla Super

A tecla Super é a que tem o logo do Windows. Ela abre a visão geral. Comece a digitar e o Ubuntu procura programas, arquivos e configurações.

  1. Aperte Super.
  2. Digite calc.
  3. Aperte Enter: a Calculadora abre.
Funciona com configurações também

Aperte Super e digite wi-fi, tela ou teclado: a tela de configuração certa aparece na busca.

A dock

A dock é a barra da lateral esquerda. Um pontinho ao lado do ícone indica que o programa está aberto.

  • Clique: abre o programa ou traz a janela para frente.
  • Botão do meio: abre uma nova janela do mesmo programa.
  • Botão direito → Adicionar aos favoritos: fixa o ícone na dock.
  • Arrastar: muda a ordem.

Posição, tamanho e comportamento da dock ficam em Configurações → Ubuntu Desktop.

Central de Aplicativos

A Central de Aplicativos (App Center) é a loja de programas do Ubuntu. Tudo nela é gratuito: procure pelo nome, clique em Instalar e digite sua senha.

Ela instala programas no formato snap e também pacotes .deb. Pelo terminal, você faz o mesmo assim:

sudo
Como administrador (instalar exige).
snap install
Instala um programa no formato snap.
vlc
O nome do programa.
$ sudo snap install vlc
[sudo: authenticate] Senha:
vlc 3.0.21 from VideoLAN✓ installed

O número da versão pode ser outro no seu computador. Veja mais em apt e Snap.

Ligando o desktop ao terminal

Os dois mundos conversam. Há formas de ir de um para o outro.

Do Arquivos para o terminal

Clique com o botão direito no fundo de uma pasta e escolha Abrir no Terminal. O terminal já abre dentro daquela pasta:

$ pwd
/home/ana/Documentos/projetos                   « a pasta em que você clicou

Do terminal para a interface: xdg-open

O xdg-open abre um arquivo ou uma pasta com o programa padrão, como se você tivesse dado dois cliques.

xdg-open
Abre com o programa padrão para aquele tipo de arquivo.
.
O ponto significa "a pasta onde estou". Abre o Arquivos nela.
$ xdg-open .
$ xdg-open manual.pdf
$ xdg-open https://ubuntu.com

Nada aparece no terminal: as janelas abrem na tela. O primeiro abre a pasta Downloads no Arquivos, o segundo abre o PDF no visualizador de documentos, e o terceiro abre o site no navegador padrão.

Quando não funciona

"O programa não está respondendo"

O que aconteceu: o programa travou ou está ocupado. O Ubuntu mostra uma janela com duas opções: Aguardar e Forçar saída.

Como resolver: espere alguns segundos. Se não voltar, clique em Forçar saída. Para encerrar pelo terminal, veja Encerrar Programas.

A tela inteira congelou

O que aconteceu: a interface gráfica travou, mas o sistema por baixo pode estar funcionando.

Como resolver: existe um terminal de emergência fora da interface, que você abre com Ctrl+Alt+F3. O passo a passo está em Quando o Sistema Trava.

O Ç e os acentos não funcionam

O que aconteceu: o layout do teclado não corresponde ao teclado físico.

Como resolver: em Configurações → Teclado, adicione Português (Brasil), que corresponde ao ABNT2. Se o seu teclado não tem Ç (padrão americano), use Inglês (EUA, internacional com teclas mortas).

xdg-open abriu no programa errado

O que aconteceu: o programa padrão para aquele tipo de arquivo é outro.

Como resolver: no Arquivos, clique com o botão direito no arquivo → Abrir com…, escolha o programa e marque para usar sempre. O xdg-open passa a usar a mesma escolha.

Resumo

  • O Ubuntu usa o GNOME. A tecla Super abre a busca: é o jeito mais rápido de abrir qualquer coisa.
  • A Central de Aplicativos instala programas com cliques; o terminal faz o mesmo com snap e apt.
  • No Arquivos, Ctrl+H mostra ocultos e Ctrl+L deixa digitar um caminho.
  • "Abrir no Terminal" leva da pasta ao terminal; xdg-open leva do terminal à interface.
  • Se a tela travar, existe o terminal de emergência: Ctrl+Alt+F3.
