Ubuntu Introdução

O Ubuntu é um sistema operacional gratuito, feito a partir do Linux. Ele roda em notebooks, computadores de mesa, servidores e na nuvem. Nesta aula você entende o que é cada uma dessas palavras e descobre, pelo terminal, qual versão está usando.

Você vai aprender
  • O que é um sistema operacional, o kernel Linux e uma distribuição.
  • De onde vem o Ubuntu e por que ele é tão usado.
  • Como ler o número da versão (26.04, 24.04…) e o que significa LTS.
  • Quatro formas de descobrir a versão instalada no seu computador.
  • A diferença entre Ubuntu Desktop, Ubuntu Server e os "sabores".

Os exemplos acontecem numa máquina fictícia chamada notebook, com a usuária ana. Não se preocupe se ainda não sabe usar o terminal: aqui você só vai ler os comandos e as respostas. Você aprende a digitar na aula O Terminal.

O que é um sistema operacional?

O sistema operacional é o programa que controla o computador. Ele liga o hardware (processador, memória, disco, rede, tela) aos programas que você usa (navegador, editor de texto, jogos).

Sem ele, cada programa teria de saber falar com cada modelo de placa de vídeo ou de Wi-Fi. Com ele, o navegador só pede "mande estes dados pela rede", e o sistema cuida do resto.

Sistema operacionalOnde costuma rodar

AndroidCelulares (por baixo, usa o kernel Linux)
UbuntuComputadores pessoais, servidores, nuvem

O que é Linux?

A palavra "Linux" tem dois sentidos, e vale separar:

  • O kernel Linux. Kernel quer dizer "núcleo". É a parte central do sistema, que conversa diretamente com o hardware. Foi criado por Linus Torvalds em 1991.
  • Um sistema Linux. O kernel junto com centenas de outros programas (terminal, utilitários, interface gráfica, instalador de programas), formando um sistema completo. O Ubuntu é um deles.

Você pode perguntar ao computador qual kernel ele está usando. O comando é o uname, de unix name, "nome do sistema":

uname
O programa: mostra informações sobre o sistema.
-r
Opção de release, "versão": mostra só a versão do kernel.
$ uname -r
7.0.0-38-generic

A resposta tem três partes:

ParteSignificado
7.0.0A versão do kernel Linux.
38A revisão feita pelo Ubuntu. Cada atualização de segurança do kernel aumenta esse número.
genericO tipo de kernel. generic é o padrão, que serve para quase todo computador.
Não precisa decorar

Você não precisa saber a versão do kernel no dia a dia. Ela é útil quando você pede ajuda num fórum ou quando um hardware novo não funciona.

O que é uma distribuição?

Uma distribuição (ou distro) é um pacote pronto para usar: kernel Linux, programas, instalador e um jeito de receber atualizações. Cada distribuição faz escolhas diferentes, mas todas usam o mesmo kernel.

DistribuiçãoBaseada emCaracterística
UbuntuDebianFácil de usar, lançamentos previsíveis, muito material de ajuda
Debian—Muito estável; é a base de várias outras
Linux MintUbuntuVisual parecido com o do Windows
Pop!_OSUbuntuVoltada a desenvolvedores e jogos
Fedora—Novidades rápidas; patrocinada pela Red Hat
Arch Linux—Montada peça por peça pelo próprio usuário
Vale para outras distribuições

Quase tudo neste guia também funciona no Debian, no Linux Mint e no Pop!_OS, porque eles usam a mesma base.

O que é o Ubuntu?

O Ubuntu foi lançado em 2004 pela empresa Canonical, fundada por Mark Shuttleworth. Ele é baseado no Debian. O nome vem de uma palavra das línguas zulu e xhosa, da África do Sul, que costuma ser traduzida como "humanidade para com os outros".

Por que ele é tão usado:

  • Gratuito: você pode baixar, instalar e usar em quantos computadores quiser.
  • Previsível: sai uma versão nova a cada 6 meses, sempre em abril e outubro.
  • Seguro: recebe correções de segurança com frequência.
  • Comunidade grande: quase todo erro que você encontrar já foi resolvido por alguém na internet.
  • Padrão na nuvem: é um dos sistemas mais usados em servidores (AWS, Azure, Google Cloud).

Como ler o número da versão

A versão do Ubuntu é sempre ano.mês do lançamento. Cada versão também ganha um codinome: um adjetivo e um animal que começam com a mesma letra.

VersãoLançamentoCodinomeTipo
26.04abril de 2026Resolute RaccoonLTS
25.10outubro de 2025Questing QuokkaIntermediária
24.04abril de 2024Noble NumbatLTS
22.04abril de 2022Jammy JellyfishLTS

Quando aparece um terceiro número, como em 26.04.1, ele indica uma revisão de manutenção. A revisão junta as atualizações publicadas desde o lançamento, para quem instala hoje não precisar baixar tudo de novo.

LTS ou intermediária?

LTS significa Long Term Support, "suporte de longo prazo". Sai uma LTS a cada 2 anos, sempre em abril dos anos pares.

LTS (ex.: 26.04)Intermediária (ex.: 25.10)
FrequênciaA cada 2 anosA cada 6 meses
Atualizações de segurança5 anos (até 10 com Ubuntu Pro)9 meses
Ideal paraUso diário, trabalho, servidoresQuem quer testar novidades
Ubuntu Pro

O Ubuntu Pro estende as atualizações de segurança de uma LTS. É gratuito para uso pessoal em até 5 máquinas. Você vê como ativar em Atualizações.

Recomendação para iniciantes

Use sempre a LTS mais recente. Este guia usa o Ubuntu 26.04 LTS.

Descobrir a versão instalada: lsb_release

O comando lsb_release mostra a versão do Ubuntu. O nome vem de Linux Standard Base, um padrão antigo para identificar distribuições.

lsb_release
O programa: informa qual distribuição e qual versão estão instaladas.
-a
Opção de all, "tudo": mostra todas as informações.
$ lsb_release -a
Distributor ID:	Ubuntu                    « a distribuição
Description:	Ubuntu 26.04.1 LTS        « nome completo, com a revisão
Release:	26.04                       « a versão
Codename:	resolute                    « o codinome, só a primeira palavra

O codinome aparece em minúsculas e só com a primeira palavra (resolute, de Resolute Raccoon). É assim que ele aparece nos endereços dos repositórios de programas, que você verá em apt.

Só o número da versão

As opções se combinam. -r pede só a versão e -s (de short, "curto") tira o rótulo da frente:

lsb_release
O programa.
-rs
Duas opções juntas: -r (versão) e -s (sem rótulo).
$ lsb_release -r
Release:	26.04
$ lsb_release -rs
26.04                                           « só o número, bom para scripts

Formas diferentes de descobrir a versão

O lsb_release é o mais conhecido, mas não é o único. Cada forma tem uma vantagem.

Forma 1: o arquivo /etc/os-release

Esse arquivo existe em praticamente todas as distribuições Linux, inclusive nas versões mínimas usadas em containers. O comando cat mostra o conteúdo de um arquivo (veja cat, less, head, tail).

$ cat /etc/os-release
PRETTY_NAME="Ubuntu 26.04.1 LTS"
NAME="Ubuntu"
VERSION_ID="26.04"
VERSION="26.04.1 LTS (Resolute Raccoon)"           « aqui aparece o codinome completo
VERSION_CODENAME=resolute
ID=ubuntu
ID_LIKE=debian                                    « o Ubuntu é "parecido com" o Debian
HOME_URL="https://www.ubuntu.com/"
SUPPORT_URL="https://help.ubuntu.com/"
BUG_REPORT_URL="https://bugs.launchpad.net/ubuntu/"
PRIVACY_POLICY_URL="https://www.ubuntu.com/legal/terms-and-policies/privacy-policy"
UBUNTU_CODENAME=resolute
LOGO=ubuntu-logo

Forma 2: hostnamectl

Mostra a versão do Ubuntu, o kernel e o computador numa tela só:

$ hostnamectl
 Static hostname: notebook
       Icon name: computer-laptop
         Chassis: laptop 💻
      Machine ID: 0e326348b23f46278827fb3f607dba88
         Boot ID: a24bc39a819e4383bb915613ee653a2f
Operating System: Ubuntu 26.04.1 LTS                « a versão
          Kernel: Linux 7.0.0-38-generic             « o kernel
    Architecture: x86-64                             « tipo de processador

Forma 3: uname -a

Com -a (all), o uname mostra tudo sobre o kernel, inclusive a arquitetura do processador:

$ uname -a
Linux notebook 7.0.0-38-generic #38-Ubuntu SMP PREEMPT_DYNAMIC Fri Sep  4 09:10:14 UTC 2026 x86_64 GNU/Linux

Ele diz que é um Ubuntu (#38-Ubuntu), mas não diz qual versão. Por isso o uname serve para o kernel, e não para a versão do sistema.

Forma 4: pela interface gráfica

No Ubuntu Desktop, abra Configurações → Sistema → Sobre. Lá aparecem a versão, o processador, a memória e o disco.

Qual forma usar?

FormaMostraMelhor quando…
lsb_release -aVersão e codinomeVocê só quer saber a versão.
cat /etc/os-releaseVersão, codinome, baseEstá num container ou numa distribuição mínima.
hostnamectlVersão, kernel, computadorVai pedir ajuda e quer tudo de uma vez.

Configurações → SobreVersão e hardwarePrefere clicar.

Missão: nesta máquina fictícia, descubra a versão do Ubuntu (use lsb_release -a ou cat /etc/os-release) e depois a versão do kernel (uname -r).

Ubuntu Desktop x Ubuntu Server

O Ubuntu tem duas edições principais. Por baixo, as duas são o mesmo sistema; o que muda é o que vem instalado.

Ubuntu DesktopUbuntu Server
Interface gráficaSim (GNOME)Não, só terminal
Uso típicoNotebook e computador pessoalSites, bancos de dados, APIs, nuvem
Programas incluídosNavegador, escritório, multimídiaSó o essencial; SSH opcional na instalação
Consumo de memóriaMaiorBem menor
Rede configurada porNetworkManagerNetplan

Os comandos deste guia funcionam nas duas edições. Quando algo for de uma só, o texto avisa. Nos exemplos de servidor, a máquina fictícia se chama servidor:

$ lsb_release -ds
Ubuntu 26.04.1 LTS

Software livre

O Ubuntu é formado principalmente por software livre: qualquer pessoa pode usar, estudar, alterar e redistribuir o código. Por isso não há licença para comprar. Os programas que você instala vêm dos repositórios oficiais, uma espécie de loja gratuita e verificada (veja apt).

Quando não funciona

"lsb_release: command not found" num container 
#> lsb_release -a
bash: lsb_release: command not found

O que aconteceu: imagens mínimas, como as do Docker, não trazem o pacote lsb-release. Repare que a mensagem está em inglês: containers costumam vir sem o idioma português instalado.

Como resolver: use cat /etc/os-release, que existe em praticamente qualquer Linux.

"Minha versão é 24.04. Preciso trocar?" 
$ lsb_release -rs
24.04

O que significa: a 24.04 é LTS e recebe atualizações de segurança até 2029. Ela continua segura.

Como decidir: se tudo funciona, pode continuar nela. Para ir para a 26.04, veja Atualizações. O do-release-upgrade só oferece a nova LTS depois da revisão 26.04.1.

"Description" diz algo diferente de Ubuntu 
$ lsb_release -ds
Linux Mint 22.2

O que significa: você está numa distribuição derivada do Ubuntu. Quase tudo deste guia funciona igual; para saber em qual Ubuntu ela se baseia, veja a linha UBUNTU_CODENAME em /etc/os-release.

Resumo

  • Linux é o kernel (núcleo); o Ubuntu é uma distribuição completa feita com ele.
  • A versão é ano.mês: 26.04 = abril de 2026. LTS sai a cada 2 anos e tem 5 anos de segurança.
  • lsb_release -a e cat /etc/os-release mostram a versão; uname -r mostra o kernel.
  • Desktop tem interface gráfica; Server é só terminal. Os comandos são os mesmos.
