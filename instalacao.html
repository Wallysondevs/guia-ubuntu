Ubuntu Instalação

Para aprender Ubuntu você precisa de um Ubuntu. A forma mais segura é uma máquina virtual: um computador simulado dentro do seu, que você pode estragar, apagar e recriar sem perder nada. Nesta aula você vê as opções, do jeito mais seguro ao mais definitivo.

Você vai aprender
  • O que é uma ISO, uma máquina virtual e um pendrive bootável.
  • Qual forma de instalação escolher, de acordo com o seu objetivo.
  • Criar e controlar máquinas virtuais com o Multipass, comando por comando.
  • Conferir se a ISO baixada não veio corrompida.
  • Fazer a primeira atualização depois de instalar.

Três ideias antes de começar

TermoO que é
ISOUm arquivo que é a "foto" de um disco de instalação, como ubuntu-26.04-desktop-amd64.iso. Você baixa uma vez e usa para instalar.
Máquina virtual (VM)Um computador de mentira, criado por um programa (VirtualBox, Multipass). Ela tem disco, memória e rede próprios, que na verdade são pedaços do seu computador.
Hospedeiro e convidadoO hospedeiro (host) é o seu computador de verdade. O convidado (guest) é o sistema que roda dentro da VM.

O que acontece dentro de uma VM fica dentro dela. Se você apagar uma pasta do sistema na VM, o seu computador nem fica sabendo.

Recomendação

Comece por uma máquina virtual. Quando estiver confortável, experimente o pendrive no seu computador e só então pense em instalar de verdade.

Requisitos mínimos do Ubuntu Desktop

  • Processador de 64 bits com 2 núcleos.
  • 4 GB de memória RAM (8 GB deixam tudo bem mais fluido).
  • 25 GB de espaço em disco.
  • Pendrive de 8 GB ou mais, se for instalar num computador de verdade.

Baixe a ISO sempre do site oficial: ubuntu.com/download.

Conferir a ISO baixada: sha256sum

Um download pode chegar corrompido, e uma ISO corrompida gera erros estranhos na instalação. O site do Ubuntu publica um arquivo chamado SHA256SUMS com a "impressão digital" de cada ISO. Se a impressão digital do seu arquivo for igual à publicada, o arquivo está perfeito.

sha256sum
O programa: calcula a impressão digital (o hash SHA-256) de um arquivo.
-c SHA256SUMS
Opção de check, "conferir": compara com a lista do arquivo SHA256SUMS.
--ignore-missing
Ignora as ISOs da lista que você não baixou.
$ ls
SHA256SUMS  ubuntu-26.04-desktop-amd64.iso
$ sha256sum -c SHA256SUMS --ignore-missing
ubuntu-26.04-desktop-amd64.iso: OK                     « OK = arquivo íntegro

Se aparecer FAILED no lugar de OK, apague a ISO e baixe de novo.

Máquina virtual com VirtualBox

O VirtualBox é um programa gratuito que cria máquinas virtuais com tela, mouse e tudo. Ele roda no Windows, no macOS e no Linux. Baixe em virtualbox.org.

  1. Baixe a ISO do Ubuntu Desktop 26.04 LTS.
  2. No VirtualBox, clique em Novo.
  3. Dê um nome (ex.: Ubuntu) e selecione a ISO baixada.
  4. Reserve 4096 MB de memória e 2 CPUs.
  5. Crie um disco virtual de pelo menos 25 GB.
  6. Clique em Finalizar e inicie a máquina.
  7. No instalador, escolha Instalar o Ubuntu. O disco que ele "apaga" é o virtual, e não o seu.
Snapshots: o botão de desfazer

Antes de testar algo arriscado, use Máquina → Criar snapshot. Se algo der errado, você volta a máquina para aquele ponto em segundos.

Máquina virtual com Multipass

O Multipass, da Canonical, cria máquinas virtuais Ubuntu sem interface gráfica com um único comando. É o jeito mais rápido de ter um "servidor" para treinar.

Instalar o Multipass

No Ubuntu, ele é instalado como snap. No Windows e no macOS, baixe o instalador em canonical.com/multipass.

sudo
Roda o comando como administrador. Instalar programas exige isso (veja sudo).
snap
O gerenciador de pacotes snap.
install
Um subcomando: diz ao snap qual ação fazer.
multipass
O nome do pacote a instalar.
$ sudo snap install multipass
[sudo: authenticate] Senha:
multipass 1.16.1 from Canonical✓ installed

A senha não aparece enquanto você digita. Isso é normal. A versão mostrada pode ser outra no seu computador.

Criar a primeira máquina

Comece pela forma mais simples: só o nome.

multipass
O programa.
launch
Subcomando que cria e liga uma máquina nova.
--name estudo
Opção com valor: o nome da máquina.
$ multipass launch --name estudo
Launched: estudo

Sem outras opções, a máquina usa a LTS mais recente, 1 CPU, 1 GB de memória e 5 GB de disco. Para estudar com folga, informe os recursos, uma opção para cada:

multipass launch
Cria e liga uma máquina.
26.04
Argumento: a versão do Ubuntu da máquina.
--name estudo2
O nome.
--cpus 2
Quantos núcleos do processador ela pode usar.
--memory 4G
Quanta memória RAM.
--disk 20G
Tamanho do disco virtual.
$ multipass launch 26.04 --name estudo2 --cpus 2 --memory 4G --disk 20G
Launched: estudo2

Ver, entrar e sair

$ multipass list
Name                    State             IPv4             Image
estudo                  Running           10.48.217.5      Ubuntu 26.04 LTS
estudo2                 Running           10.48.217.9      Ubuntu 26.04 LTS

Cada linha é uma máquina: nome, estado (Running = ligada, Stopped = desligada), endereço de rede e versão. Para abrir um terminal dentro dela, use shell:

$ multipass shell estudo
Welcome to Ubuntu 26.04.1 LTS (GNU/Linux 7.0.0-38-generic x86_64)
...

Agora o prompt muda: você está dentro da máquina virtual, com o usuário ubuntu. Tudo o que digitar aqui acontece nela:

$ hostname
estudo
$ exit
logout

O exit fecha a sessão e você volta para o terminal do seu computador.

Rodar um comando sem entrar

Com exec, você manda um comando para a máquina e recebe a resposta, sem abrir uma sessão. Os dois hífens -- separam as opções do Multipass do comando que vai rodar lá dentro.

$ multipass exec estudo -- lsb_release -rs
26.04

Desligar, ligar e apagar

$ multipass stop estudo
$ multipass start estudo
$ multipass delete estudo2
$ multipass purge

Nenhum desses comandos mostra mensagem quando dá certo. Confira com multipass list.

Atenção: delete + purge não tem volta

multipass delete manda a máquina para a lixeira (dá para recuperar com multipass recover). Depois de multipass purge, a máquina e todos os arquivos dentro dela somem para sempre.

ComandoO que faz
multipass findLista as versões disponíveis para criar máquinas
multipass launch --name <nome>Cria e liga uma máquina
multipass listLista as máquinas, o estado e o IP
multipass shell <nome>Abre um terminal dentro da máquina
multipass exec <nome> -- <comando>Roda um comando lá dentro sem entrar
multipass info <nome>Mostra CPU, memória, disco e IP
multipass stop / startDesliga / liga
multipass delete / recoverManda para a lixeira / tira da lixeira
multipass purgeEsvazia a lixeira de vez

Ubuntu no Windows com WSL

O WSL (Windows Subsystem for Linux, "subsistema Windows para Linux") roda o Ubuntu dentro do Windows 10 ou 11. Você ganha o terminal do Ubuntu, mas não a interface gráfica completa. Estes comandos são digitados no PowerShell do Windows, aberto como administrador:

wsl --list --online
wsl --install -d Ubuntu

O primeiro comando lista as distribuições disponíveis e o nome exato de cada uma (por exemplo, para escolher uma versão específica). O segundo instala. Reinicie o computador se for pedido. Na primeira vez que o Ubuntu abrir, ele pede para criar um usuário e uma senha. Essa é a senha que o sudo vai pedir depois.

Comando (no PowerShell)O que faz
wsl --list --onlineLista as distribuições que podem ser instaladas
wsl --install -d <nome>Instala uma distribuição
wsl -l -vLista as instaladas e a versão do WSL
wslAbre a distribuição padrão
wsl --shutdownDesliga todas as distribuições
Diferenças do WSL

No WSL, os discos do Windows aparecem em /mnt/c, /mnt/d e assim por diante. Alguns recursos, como serviços do sistema e drivers, funcionam diferente de um Ubuntu instalado de verdade.

Pendrive bootável

Para instalar o Ubuntu num computador de verdade, ou só testá-lo sem instalar, grave a ISO num pendrive. Há várias formas:

FerramentaSistemaObservação
balenaEtcherWindows, macOS e LinuxA mais simples: escolha a ISO, o pendrive e clique em Flash
RufusWindowsMuito usada no Windows
Criador de discos de inicializaçãoUbuntuJá vem no Ubuntu Desktop
Discos → Restaurar imagem de discoUbuntuOutra opção gráfica do Ubuntu
dd no terminalLinuxRápido, mas perigoso se você errar o destino
Gravar a ISO apaga o pendrive

Tudo o que estiver no pendrive é perdido. Copie os arquivos dele antes.

Gravando com dd

Primeiro, descubra o nome do pendrive com lsblk (veja lsblk, df, du). Olhe o tamanho e a coluna TRAN: pendrives aparecem como usb.

$ lsblk -d -o NAME,SIZE,TRAN,MODEL
NAME      SIZE TRAN   MODEL
nvme0n1 476,9G nvme   WDC PC SN530          « o disco do sistema: NÃO é esse
sdb      14,6G usb    SanDisk Ultra         « o pendrive de 16 GB
sudo dd
O dd copia dados byte a byte. Precisa de sudo para escrever no pendrive.
if=ubuntu-26.04-desktop-amd64.iso
input file: de onde ler (a ISO).
of=/dev/sdb
output file: onde escrever (o pendrive inteiro, sem número no fim).
bs=4M
Copia em blocos de 4 MB, o que deixa mais rápido.
status=progress
Mostra o progresso enquanto copia.
conv=fsync
Só termina quando tudo estiver gravado de fato no pendrive.
$ sudo dd if=ubuntu-26.04-desktop-amd64.iso of=/dev/sdb bs=4M status=progress conv=fsync
[sudo: authenticate] Senha:
1510+1 registros entrados
1510+1 registros saídos
6333579264 bytes (6.3 GB, 5.9 GiB) copiados, 412.71 s, 15.3 MB/s
Cuidado redobrado com o dd

Se você errar o of=, o dd apaga o disco errado sem perguntar nada, inclusive o disco do seu sistema. Confira o nome três vezes. Na dúvida, use o balenaEtcher.

Iniciando pelo pendrive

  1. Com o pendrive conectado, reinicie o computador.
  2. Logo ao ligar, aperte a tecla do menu de inicialização. Costuma ser F12, F11, F10, F8 ou Esc, conforme o fabricante.
  3. Escolha o pendrive na lista.
  4. No menu do Ubuntu, escolha Try or Install Ubuntu.
  5. Para só testar, escolha Experimentar o Ubuntu. Nada é gravado no disco.

Dual boot com o Windows

Dual boot é ter dois sistemas no mesmo computador e escolher qual usar ao ligar. O instalador do Ubuntu detecta o Windows e oferece instalar ao lado dele.

  1. Faça backup de todos os arquivos importantes. Mexer em partições sempre tem risco.
  2. Se o disco usa BitLocker, anote a chave de recuperação antes de qualquer coisa.
  3. No Windows, desative a Inicialização rápida (Painel de Controle → Opções de energia).
  4. Libere espaço: em Gerenciamento de Disco → Diminuir volume, deixe pelo menos 25 GB livres.
  5. Inicie pelo pendrive e escolha Instalar o Ubuntu.
  6. Na etapa do disco, escolha instalar ao lado do Windows.
  7. Ao final, toda vez que ligar o computador aparece o menu do GRUB para escolher Ubuntu ou Windows.
"Apagar disco e instalar o Ubuntu"

Essa opção remove o Windows e todos os arquivos do disco. Use só se tiver certeza e backup.

A primeira atualização

A ISO foi gerada num certo dia. Depois de instalar, baixe as atualizações publicadas desde então. São dois passos, e cada um tem uma função:

sudo
Como administrador.
apt
O gerenciador de pacotes do Ubuntu.
update
Atualiza a lista do que existe de novo. Não instala nada.
$ sudo apt update
[sudo: authenticate] Senha:
Atingido:1 http://br.archive.ubuntu.com/ubuntu resolute InRelease
Obter:2 http://br.archive.ubuntu.com/ubuntu resolute-updates InRelease [126 kB]
Obter:3 http://security.ubuntu.com/ubuntu resolute-security InRelease [126 kB]
...
Lendo listas de pacotes... Pronto
12 pacotes podem ser atualizados. Execute 'apt list --upgradable' para vê-los.

Agora o segundo passo, que realmente instala as novidades:

sudo apt
O gerenciador de pacotes, como administrador.
upgrade
Instala as versões novas dos pacotes já instalados.
-y
Responde "sim" sozinho à pergunta de confirmação.
$ sudo apt upgrade -y
Lendo listas de pacotes... Pronto
Construindo árvore de dependências... Pronto
Lendo informação de estado... Pronto
Calculando atualização... Pronto
...
Resumo:
  Atualizando: 12, Instalando: 0, Removendo: 0, Não atualizando: 0
...

Os programas instalados como snap se atualizam sozinhos, mas você pode forçar com sudo snap refresh. Os detalhes estão em apt e Atualizações.

Precisa reiniciar?

Se a atualização trouxe um kernel novo, o Ubuntu cria o arquivo /var/run/reboot-required. Basta ver se ele existe:

$ cat /var/run/reboot-required
*** System restart required ***                         « reinicie quando puder

Se a resposta for cat: /var/run/reboot-required: No such file or directory, não é preciso reiniciar.

Formas de atualizar

FormaComoMelhor quando…
Terminalsudo apt update && sudo apt upgrade -yVocê quer ver o que está acontecendo, ou está num servidor.
Atualizador de ProgramasSuper → "Atualizador de Programas"Prefere clicar. Ele também avisa sozinho quando há atualizações.
Automáticaunattended-upgrades (já vem ligado)Correções de segurança, sem você fazer nada.

O && roda o segundo comando só se o primeiro der certo. Você aprende isso em Sintaxe dos Comandos.

Quando não funciona

"Não foi possível obter a trava" logo depois de instalar 
$ sudo apt upgrade
Erro: Não foi possível obter a trava /var/lib/dpkg/lock-frontend. Ela está sendo mantida pelo processo 2154 (unattended-upgr)

O que aconteceu: o Ubuntu está baixando atualizações sozinho em segundo plano (unattended-upgr). Só um programa pode instalar pacotes por vez.

Como resolver: espere alguns minutos e tente de novo. Não apague arquivos de trava à força.

A máquina virtual não liga: "VT-x is not available"

O que aconteceu: a virtualização do processador (Intel VT-x ou AMD-V/SVM) está desligada na BIOS/UEFI do computador.

Como resolver: entre na configuração da BIOS/UEFI (geralmente Del ou F2 ao ligar) e ative a opção de virtualização. No Linux, confira se o processador suporta com grep -c -E 'vmx|svm' /proc/cpuinfo: qualquer número acima de 0 indica que sim.

A máquina virtual está muito lenta

Como resolver: dê 4 GB de memória e 2 CPUs para a VM. Se o seu computador tem só 8 GB, feche outros programas enquanto usa a VM, ou prefira o Multipass, que não tem interface gráfica e gasta menos.

O computador não inicia pelo pendrive

Como resolver: use o menu de inicialização (F12 e similares) em vez de mudar a ordem de boot. Se o pendrive não aparece, grave a ISO de novo com outra ferramenta e confira a ISO com sha256sum.

"sha256sum: WARNING: 1 computed checksum did NOT match" 
$ sha256sum -c SHA256SUMS --ignore-missing
ubuntu-26.04-desktop-amd64.iso: FAILED
sha256sum: WARNING: 1 computed checksum did NOT match

O que aconteceu: o arquivo baixado não é idêntico ao publicado. O download foi interrompido ou corrompido.

Como resolver: apague a ISO e baixe de novo, de preferência por cabo de rede.

Resumo

  • Para estudar, use uma máquina virtual: Multipass (só terminal) ou VirtualBox (com interface).
  • Confira a ISO com sha256sum -c SHA256SUMS --ignore-missing.
  • multipass launch, list, shell, stop, delete e purge controlam as máquinas.
  • No dd, confira o of= três vezes. Na dúvida, use o balenaEtcher.
  • Depois de instalar: sudo apt update e sudo apt upgrade.
