Ubuntu pwd e cd

No terminal você está sempre "dentro" de alguma pasta, chamada pasta atual ou diretório de trabalho. O pwd diz qual é. O cd muda de pasta. Com esses dois, você anda pela árvore de diretórios como faz com o mouse no app Arquivos.

Você vai aprender
  • Descobrir onde você está, pelo prompt e pelo pwd.
  • Entrar numa pasta, voltar um nível, ir para a pasta pessoal e para a raiz.
  • Alternar entre duas pastas com cd - e guardar caminhos com pushd/popd.
  • Entender as mensagens de erro do cd.

A ideia: o terminal está sempre em algum lugar

Quando você abre o terminal, ele começa na sua pasta pessoal, /home/ana. Todo caminho relativo que você digitar (veja Caminhos) parte dessa pasta. Mudar de pasta muda o ponto de partida.

O próprio prompt mostra a pasta atual, entre os dois-pontos e o $:

$ cd Documentos
$ cd projetos
$ cd /etc

Observe como o prompt muda a cada linha: ~, depois ~/Documentos, depois ~/Documentos/projetos, e por fim /etc. O cd não mostra nada quando dá certo; a "resposta" é o prompt novo.

pwd: onde estou?

pwd vem de print working directory, "mostrar o diretório de trabalho". O prompt abrevia a pasta pessoal como ~; o pwd mostra o caminho absoluto completo.

pwd
Mostra o caminho absoluto da pasta atual. Não precisa de argumentos.
$ pwd
/home/ana/Documentos/projetos

O caminho "de verdade": pwd -P

Algumas pastas são atalhos (links) para outras. No Ubuntu, /bin é um atalho para /usr/bin. O pwd mostra o caminho por onde você entrou; com -P (de physical, "físico"), mostra onde você realmente está:

$ pwd
/bin
$ pwd -P
/usr/bin           « /bin é só um atalho para /usr/bin

cd: mudar de pasta

cd vem de change directory, "mudar de diretório". Ele recebe um caminho, absoluto ou relativo.

cd
O comando. Ele faz parte do próprio shell (bash), não é um programa separado.
Documentos
Para onde ir. Aqui, um caminho relativo: a pasta Documentos dentro da atual.
$ pwd
/home/ana
$ cd Documentos
$ pwd
/home/ana/Documentos
$ ls
acesso.log  notas.txt  projetos  relatorio.odt

Subir e descer

$ cd Documentos/projetos/site
$ pwd
/home/ana/Documentos/projetos/site
$ cd ..
$ pwd
/home/ana/Documentos/projetos
$ cd ../..
$ pwd
/home/ana

Você pode descer vários níveis num comando só (cd Documentos/projetos/site) em vez de três cd separados.

Voltar para casa

Esteja onde estiver, cd sozinho leva para a pasta pessoal. É a forma mais rápida de "se achar" quando você se perdeu.

$ cd
$ pwd
/home/ana

Missão: chegue em ~/Documentos/projetos/site. Depois volte para casa com um único comando e entre de novo, desta vez com um só cd. Termine dentro de site.

Alternar entre duas pastas: cd -

O hífen significa "a pasta anterior". O cd - volta para lá e mostra o caminho. Repetir cd - alterna entre as duas, como o "voltar" do navegador.

$ cd /var/log
$ cd ~/Documentos
$ cd -
/var/log
$ cd -
/home/ana/Documentos

É útil quando você edita uma configuração em /etc e confere o log em /var/log, indo e voltando.

Uma pilha de pastas: pushd e popd

O cd - lembra só uma pasta. Para lembrar várias, use a pilha de diretórios. pushd ("empurre") entra numa pasta e guarda a atual na pilha. popd ("tire") volta para a última guardada.

pushd
Guarda a pasta atual na pilha e entra na pasta indicada.
/etc
Para onde ir.
$ pushd /etc
/etc ~                 « a pilha: estou em /etc, e ~ está guardada
$ pushd /tmp
/tmp /etc ~
$ popd
/etc ~                 « voltei para /etc
$ popd
~                      « e para casa

A linha que eles mostram é a pilha, da esquerda (pasta atual) para a direita. dirs -v mostra a pilha numerada.

Estando em /home/ana/Documentos/projetos, todos estes levam a /home/ana/Downloads:

Abrir o terminal numa pasta pelo app Arquivos

No app Arquivos, clique com o botão direito numa área vazia da pasta e escolha Abrir no terminal. O terminal abre já dentro dela.

Quando não funciona

"Arquivo ou diretório inexistente" 
$ cd documentos
bash: cd: documentos: Arquivo ou diretório inexistente

O que aconteceu: não existe uma pasta com esse nome exato na pasta atual. Pode ser maiúscula/minúscula, erro de digitação, ou você está em outra pasta.

Como confirmar: pwd para ver onde você está e ls para ver o que existe ali.

Como resolver: use o Tab para completar o nome.

"Não é um diretório" 
$ cd frutas.txt
bash: cd: frutas.txt: Não é um diretório

O que aconteceu: frutas.txt é um arquivo. Só dá para "entrar" em pastas.

Como resolver: para ver o conteúdo do arquivo, use cat frutas.txt (veja cat, less, head, tail).

"Permissão negada" 
$ cd /root
bash: cd: /root: Permissão negada

O que aconteceu: sua conta não tem permissão de entrar nessa pasta.

Como resolver: sudo cd não funciona, porque o cd faz parte do shell, e não é um programa que o sudo possa executar. Se precisar trabalhar como administrador, use sudo -i e depois exit (veja sudo).

"número excessivo de argumentos" 
$ cd Área de trabalho
bash: cd: número excessivo de argumentos

O que aconteceu: o espaço separou o nome em três argumentos, e o cd aceita só um.

Como resolver: cd "Área de trabalho".

"OLDPWD não definida" 
$ cd -
bash: cd: OLDPWD não definida

O que aconteceu: você ainda não mudou de pasta neste terminal, então não existe "pasta anterior".

Resumo

  • O prompt mostra a pasta atual; pwd mostra o caminho completo.
  • cd pasta entra, cd .. sobe, cd volta para casa, cd - alterna.
  • cd não mostra nada quando dá certo: confira pelo prompt.
  • pushd/popd guardam e recuperam várias pastas.
  • Para pastas do root, sudo cd não serve; use sudo -i.
