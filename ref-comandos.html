Ubuntu Referência de Comandos

Esta página lista os 220 comandos ensinados no guia, de A a Z. Cada linha diz o que o comando faz em uma frase, em qual nível ele aparece e qual aula explica ele parte por parte. Se você sabe o que quer fazer mas não sabe o comando, pule para Por tarefa.

Como usar esta página
  • Use Ctrl+F no navegador para achar um comando rápido.
  • A coluna Nível indica a trilha: 1 = Iniciante, 2 = Intermediário, 3 = Avançado.
  • Uma frase não ensina um comando. Antes de usar algo novo, abra a aula: lá estão as opções, a saída explicada e os erros comuns.

Antes de rodar um comando que você não conhece

Três perguntas rápidas evitam a maioria dos sustos: o comando existe? O que ele é? O que ele faz?

type
Pergunta ao shell o que é aquele nome: programa, apelido ou comando interno.
rsync
O nome que você quer conhecer.
$ type rsync
rsync é /usr/bin/rsync                              « existe e é um programa
$ whatis rsync
rsync (1)            - a fast, versatile, remote (and local) file-copying tool
$ type ll
ll está apelidada para `ls -alF'                    « é um apelido do ~/.bashrc
$ type xyz
bash: type: xyz: não encontrado                     « não existe neste sistema

Depois disso, man rsync abre o manual completo e rsync --help mostra o resumo das opções. A aula Obtendo Ajuda ensina a ler os dois.
