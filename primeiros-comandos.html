Ubuntu Primeiros Comandos

Antes de mexer em arquivos, vale conhecer a máquina em que você está. Os comandos desta aula só leem informações: não mudam nada, não apagam nada. São perfeitos para treinar a digitação, as opções e a leitura das respostas.

Você vai aprender
  • Perguntar quem você é (whoami) e em qual máquina está (hostname).
  • Mostrar a data e a hora em qualquer formato com date.
  • Ver o calendário (cal) e há quanto tempo o computador está ligado (uptime).
  • Escrever na tela com echo, inclusive o resultado de outros comandos.
  • Limpar a tela, sair e rever o que você digitou.

Quem sou eu? whoami

whoami é a frase inglesa who am I?, "quem sou eu?", escrita junta. Ele mostra o nome do usuário que está usando o terminal.

whoami
O comando inteiro. Não precisa de opções nem de argumentos.
$ whoami
ana

Parece óbvio, já que o nome aparece no prompt. Mas ele fica útil quando você usa sudo, entra em outro computador por SSH ou escreve scripts:

$ sudo whoami
[sudo: authenticate] Senha:
root                                            « com sudo, o comando roda como administrador

O uid=1000 é o número da Ana no sistema. O 27(sudo) na lista de grupos diz que ela pode usar sudo. Você aprende mais em Usuários e Grupos.

Qual é a máquina? hostname

Hostname é o "nome do hospedeiro": o nome do computador na rede.

$ hostname
notebook
$ hostname -I
192.168.0.15                                    « -I mostra o endereço IP

Num servidor, o prompt e o hostname mostram o nome dele. Isso evita rodar um comando na máquina errada:

$ hostname
servidor

Data e hora: date

Sem nada, o date mostra a data e a hora completas:

$ date
qui. 15 out 2026 10:30:00 -03

O -03 no fim é o fuso horário: três horas a menos que o horário universal (UTC), como em Brasília.

Escolhendo o formato

Para escolher o formato, passe um argumento que começa com +. Cada % com uma letra é trocado por um pedaço da data:

date
O programa.
+"%d/%m/%Y"
O formato: o + avisa que é um formato; %d dia, %m mês, %Y ano. As barras ficam como estão.
$ date +"%d/%m/%Y"
15/10/2026
$ date +%F
2026-10-15                                      « formato internacional, ótimo para nomes de arquivo
$ date +%H:%M
10:30
$ date +"%A, %d de %B de %Y"
quinta-feira, 15 de outubro de 2026

As aspas só são necessárias quando o formato tem espaços.

Outras datas: -d

A opção -d (de date) calcula outra data em vez de hoje. Ela entende expressões em inglês ou datas no formato AAAA-MM-DD:

$ date -d tomorrow +%F
2026-10-16
$ date -d "+3 days" +%F
2026-10-18
$ date -d "2026-12-25" +%A
sexta-feira                                     « em que dia da semana cai o Natal

Calendário: cal

O cal (de calendar) desenha o calendário do mês. Ele não vem instalado; o Ubuntu sugere o pacote:

$ cal
Comando 'cal' não encontrado, mas poder ser instalado com:
sudo apt install ncal
$ sudo apt install ncal

Há quanto tempo está ligado? uptime

Uptime é o "tempo de pé": quanto tempo faz que o computador foi ligado.

$ uptime
 10:30:00 up  2:31,  1 user,  load average: 0,42, 0,38, 0,35
PedaçoSignificado
10:30:00A hora atual.
up 2:31Ligado há 2 horas e 31 minutos.
1 userUma pessoa conectada.
load averageA "carga" do processador no último minuto, nos últimos 5 e nos últimos 15. Veja ps, pgrep, top.

Duas opções deixam a resposta mais fácil de ler:

$ uptime -p
up 2 hours, 31 minutes                          « -p: pretty, "bonito"
$ uptime -s
2026-10-15 07:59:00                             « -s: since, "desde quando"

Você já viu esses dois na Introdução. Um resumo:

Escrever na tela: echo

O echo mostra o texto que recebeu. Ele parece simples demais, mas é usado o tempo todo para ver variáveis e montar mensagens em scripts.

$ echo "Bom dia!"
Bom dia!
$ echo "Minha pasta pessoal é $HOME"
Minha pasta pessoal é /home/ana

O $HOME é uma variável: o shell troca pelo valor dela antes de chamar o echo.

O resultado de um comando dentro do texto: $( )

Tudo o que estiver dentro de $( ) é executado primeiro, e a resposta entra no lugar. Isso se chama substituição de comando.

echo
Mostra o texto.
"Hoje é $(date +%d/%m)"
O texto. O $(date +%d/%m) roda antes e vira 15/10.
$ echo "Hoje é $(date +%d/%m)"
Hoje é 15/10
$ echo "Sou $(whoami) e estou em $(hostname)"
Sou ana e estou em notebook
OpçãoDescriçãoExemplo
-nNão pula linha no finalecho -n "Sem quebra"
-eEntende \n (nova linha) e \t (tabulação)echo -e "linha1\nlinha2"
$ echo -e "Nome:\tAna\nCidade:\tRecife"
Nome:	Ana
Cidade:	Recife

Missão: crie o arquivo info.txt com o seu usuário, o nome da máquina e a data no formato 2026-10-15, sem digitar esses valores à mão. Use echo, $( ) e >. Confira com cat info.txt.

Quando não funciona

"data inválida" no date -d 
$ date -d amanhã
date: data inválida 'amanhã'

O que aconteceu: o -d entende expressões só em inglês.

Como resolver: date -d tomorrow, date -d "next friday", date -d "+3 days" ou uma data AAAA-MM-DD.

"you must be root to change the host name" 
$ hostname meu-pc
hostname: you must be root to change the host name

O que aconteceu: com um argumento, o hostname tenta trocar o nome da máquina, o que exige administrador. A mensagem vem em inglês mesmo.

Como resolver: se a ideia era só ver o nome, rode hostname sem nada. Para trocar de verdade, use sudo hostnamectl set-hostname meu-pc (veja Configurar a Rede).

"argumento inesperado" no whoami 
$ whoami ana
erro: argumento inesperado 'ana' encontrado

Uso: whoami

Para obter mais informações, use '--help'.

O que aconteceu: o whoami não recebe argumentos. A linha Uso: whoami mostra isso: não há nada depois do nome.

Como resolver: rode só whoami. Para ver os dados de outro usuário, use id ana.

"cal: comando não encontrado"

O que aconteceu: o programa não está instalado. O Ubuntu sugere sudo apt install ncal.

Como resolver: instale o pacote sugerido. Veja apt.

Resumo

  • whoami, id e hostname dizem quem você é e onde está.
  • date +FORMATO mostra a data do jeito que você quiser; %F dá 2026-10-15. -d calcula outras datas (em inglês).
  • cal (pacote ncal) mostra o calendário; uptime -p, o tempo ligado.
  • echo escreve na tela; $( ) coloca o resultado de um comando dentro do texto.
  • clear limpa, exit sai, history mostra o que você digitou.
