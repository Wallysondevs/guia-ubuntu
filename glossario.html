Ubuntu Glossário

Os 113 termos técnicos usados no guia, em ordem alfabética, cada um explicado em uma ou duas frases e com o link para a aula onde ele aparece. Quando uma palavra de uma aula parecer estranha, procure aqui com Ctrl+F.

Termos em inglês

Muitos nomes ficam em inglês porque é assim que aparecem nos comandos, nos manuais e nas mensagens de erro. Quando existe um nome em português de uso comum, ele aparece entre parênteses.

A · B · C · D · E · F · G · H · I · J · K · L · M · N · O · P · R · S · T · U · V · W · Y · Z

A

Absoluto (caminho)
Caminho que começa na raiz /, como /home/ana/Documentos. Funciona de qualquer pasta. Veja: Caminhos.
ACL
Lista de controle de acesso: permissões extras, por usuário, além de dono/grupo/outros. Veja: Entendendo Permissões.
Alias (apelido)
Nome curto que o shell troca por um comando maior. Ex.: ll vira ls -alF. Veja: .bashrc, alias, PATH.
Ancoragem (tethering)
Usar a internet do celular no computador, pelo cabo USB, Wi-Fi ou Bluetooth. Veja: Celular e Modem 4G.
APN
"Nome do ponto de acesso": o endereço que a operadora usa para liberar a internet do chip. Veja: Onde achar o APN.
AppArmor
Proteção do Ubuntu que limita o que cada programa pode acessar. Veja: Segurança do Servidor.
apt
Gerenciador de pacotes do Ubuntu: instala, atualiza e remove programas dos repositórios. Veja: apt.
Argumento
O que você entrega ao comando para ele trabalhar, como o nome de um arquivo. Veja: Sintaxe dos Comandos.

B

Backup
Cópia dos dados guardada em outro lugar, para recuperar depois. Só vale se a restauração for testada. Veja: Backup.
Bash
O shell padrão do Ubuntu: o programa que lê e executa o que você digita no terminal. Veja: O Terminal.
Branch
Linha de desenvolvimento separada no Git, onde você muda coisas sem mexer na principal. Veja: Git.

C

Cache
Cópia guardada para acelerar acessos futuros. Na memória, aparece como buff/cache no free. Veja: Desempenho e Monitoramento.
Caminho
O endereço de um arquivo ou pasta, como Documentos/notas.txt. Veja: Caminhos.
Certificado
Arquivo que prova a identidade de um site e permite o HTTPS. O Let's Encrypt emite de graça. Veja: HTTPS (Let's Encrypt).
chroot
Técnica de rodar um shell "dentro" de outro sistema montado; usada para consertar um Ubuntu que não liga. Veja: Recuperar um Sistema.
CIDR
Forma curta de escrever a máscara de rede: /24 equivale a 255.255.255.0. Veja: Conceitos de Rede.
cloud-init
Ferramenta que configura uma máquina nova no primeiro boot a partir de um arquivo user-data. Veja: cloud-init.
Código de saída
Número que todo comando devolve ao terminar: 0 é sucesso, outro número é erro. Veja com echo $?. Veja: touch e mkdir.
Commit
Fotografia do projeto guardada no Git, com uma mensagem explicando o que mudou. Veja: Git.
Container
Ambiente isolado que roda um programa com tudo de que ele precisa, dividindo o kernel com a máquina. Veja: Docker.
cron
Serviço que executa tarefas em horários marcados. Veja: Agendar Tarefas (cron).
Curinga (glob)
Símbolo que representa nomes de arquivos: * (qualquer coisa), ? (um caractere), [abc]. Veja: Curingas.

D

Daemon
Programa que roda em segundo plano, sem janela, como o servidor SSH. Veja: systemctl.
deb (.deb)
Formato de pacote do Debian e do Ubuntu. Veja: dpkg e .deb.
Dependência
Outro pacote que um programa precisa para funcionar. O apt instala sozinho. Veja: apt.
Diretório
Nome técnico de pasta. Veja: Estrutura de Diretórios.
Distribuição (distro)
Um sistema completo montado em volta do kernel Linux, como Ubuntu, Debian ou Fedora. Veja: Introdução.
DKMS
Sistema que recompila sozinho drivers de fora do kernel a cada kernel novo (pacotes -dkms). Veja: Drivers.
DNS
Serviço que traduz nomes (ubuntu.com) em endereços IP. É a "agenda" da internet. Veja: Conceitos de Rede.
Docker
Ferramenta para criar e rodar containers a partir de imagens. Veja: Docker.
Dotfile
Arquivo de configuração cujo nome começa com ponto, como .bashrc. Fica oculto. Veja: .bashrc, alias, PATH.

E

Expansão de chaves
Recurso do shell que gera vários nomes: {a,b} e {1..5}. Veja: touch e mkdir.
ext4
Sistema de arquivos padrão do Ubuntu. Veja: Particionar e Formatar.

F

Firewall
Filtro que decide quais conexões de rede entram e saem. No Ubuntu: ufw e nftables. Veja: Firewall (ufw).
Firmware
Programa que roda dentro de um aparelho (placa Wi-Fi, vídeo). No Linux, os arquivos vêm no pacote linux-firmware. Veja: Firmware.
Flatpak
Formato de pacote de apps isolados, distribuídos principalmente pelo Flathub. Veja: Flatpak.
fstab
Arquivo /etc/fstab que diz quais discos montar no boot. Um erro nele pode impedir o sistema de ligar. Veja: mount e fstab.

G

Gateway
O roteador por onde seu computador sai para outras redes e para a internet. Veja: Conceitos de Rede.
GNOME
O ambiente gráfico (desktop) padrão do Ubuntu. Veja: O Desktop.
GPT
Esquema moderno de tabela de partições, usado com UEFI. O antigo é o MBR. Veja: Particionar e Formatar.
GRUB
Carregador de boot: o menu que aparece antes do Ubuntu e carrega o kernel. Veja: Boot, GRUB e Kernel.
Grupo
Conjunto de usuários que compartilham permissões, como o grupo sudo. Veja: Usuários e Grupos.

H

Home (pasta pessoal)
A sua pasta, /home/seu-usuario, representada por ~. Veja: Estrutura de Diretórios.
HTTPS
HTTP com criptografia (TLS). Precisa de um certificado. Veja: HTTPS (Let's Encrypt).

I

Idempotência
Propriedade de algo que pode rodar várias vezes com o mesmo resultado. Os playbooks do Ansible são assim. Veja: Ansible.
Imagem (Docker)
Modelo somente-leitura de onde os containers nascem, como nginx ou postgres. Veja: Docker.
initramfs
Mini-sistema carregado junto com o kernel no boot, que prepara os discos antes do Ubuntu de verdade. Veja: Boot, GRUB e Kernel.
Inode
Registro interno onde o sistema de arquivos guarda os dados de um arquivo (dono, permissões, onde estão os blocos). Veja: Links (ln).
IP
Endereço numérico de uma máquina na rede, como 192.168.0.15. Veja: Conceitos de Rede.

J

Job (trabalho)
Comando iniciado num terminal, em primeiro ou segundo plano. Veja: Jobs, nohup, tmux.
Journal
O registro de logs do systemd, lido com journalctl. Veja: Logs (journalctl).

K

Kernel
O núcleo do sistema: conversa com o hardware e divide CPU e memória entre os programas. O Linux é um kernel. Veja: Introdução.
KVM
Recurso do kernel que permite rodar máquinas virtuais com velocidade quase nativa. Veja: KVM e virt-manager.

L

Link físico (hard link)
Outro nome para o mesmo arquivo (mesmo inode). Veja: Links (ln).
Link simbólico
Atalho que aponta para outro caminho. Se o alvo sumir, o link fica quebrado. Veja: Links (ln).
Load average
Média de processos querendo CPU no último 1, 5 e 15 minutos (uptime). Veja: Desempenho e Monitoramento.
Log
Registro do que aconteceu no sistema ou num programa. Veja: Logs (journalctl).
LTS
Long Term Support: versão do Ubuntu com 5 anos de atualizações, lançada a cada 2 anos (ex.: 26.04). Veja: Introdução.
LV (volume lógico)
No LVM, a "partição" flexível que você formata e monta, e que pode crescer depois. Veja: LVM.
LVM
Camada que junta discos e cria volumes que podem ser aumentados sem reparticionar. Veja: LVM.
LXD
Gerenciador de containers de sistema (um Ubuntu inteiro isolado) e de VMs. Veja: LXD.

M

Máscara de rede
Indica qual parte do IP é a rede e qual é a máquina (ex.: 255.255.255.0 ou /24). Veja: Conceitos de Rede.
Montar
Ligar um disco ou partição a uma pasta, para acessar o conteúdo dele. Veja: mount e fstab.

N

Netplan
Sistema de configuração de rede do Ubuntu Server, em arquivos YAML. Veja: Configurar a Rede.
nftables
O firewall do kernel Linux atual; o ufw trabalha em cima dele. Veja: nftables.
nginx
Servidor web leve, usado também como proxy reverso. Veja: Servidor Web (nginx).

O

Octal (permissões)
Permissões escritas em números: r=4, w=2, x=1. 755 = rwxr-xr-x. Veja: chmod.
Opção (flag)
Modificador de um comando que começa com hífen, como -l ou --all. Veja: Sintaxe dos Comandos.

P

Pacote
Arquivo com um programa e as informações para instalá-lo. Veja: apt.
Partição
Divisão de um disco que funciona como um disco separado. Veja: Particionar e Formatar.
PATH
Lista de pastas onde o shell procura os programas que você digita. Veja: .bashrc, alias, PATH.
Permissão
Regra de quem pode ler (r), escrever (w) e executar (x) cada arquivo. Veja: Entendendo Permissões.
PID
Número de identificação de um processo. Veja: ps, pgrep, top.
Pipe
O |: liga a saída de um comando à entrada do próximo. Veja: Pipes e xargs.
Playbook
Arquivo YAML do Ansible com a lista de tarefas para deixar servidores no estado desejado. Veja: Ansible.
Pool (ZFS)
Conjunto de discos que o ZFS administra como um só espaço de armazenamento. Veja: ZFS.
Porta
Número que identifica um serviço numa máquina: 22 é SSH, 80 é HTTP, 443 é HTTPS. Veja: Conceitos de Rede.
PPA
Repositório pessoal no Launchpad com versões extras de programas. Use com cuidado. Veja: Repositórios e PPAs.
Processo
Um programa em execução. Veja: ps, pgrep, top.
Prompt
O texto antes do cursor, como ana@notebook:~$: diz quem, onde e que o terminal espera um comando. Veja: O Terminal.
Proxy reverso
Servidor (ex.: nginx) que recebe as visitas e repassa para uma aplicação escondida atrás dele. Veja: Servidor Web (nginx).
PV (volume físico)
No LVM, um disco ou partição preparado com pvcreate. Veja: LVM.

R

RAID
Combinação de discos para ganhar velocidade, segurança contra falha de disco, ou os dois. Veja: RAID (mdadm).
Recovery mode
Modo de recuperação no menu do GRUB que dá um shell de root para consertar o sistema. Veja: Recuperar um Sistema.
Redirecionamento
Mandar a saída de um comando para um arquivo (>, >>) ou ler de um arquivo (<). Veja: Redirecionamento.
Regex (expressão regular)
Padrão para procurar texto, como ^Erro (linhas que começam com Erro). Veja: grep.
Relativo (caminho)
Caminho que parte da pasta atual, como Documentos/notas.txt. Veja: Caminhos.
Repositório
Servidor de onde o apt baixa os pacotes. Também: a pasta de um projeto no Git. Veja: Repositórios e PPAs.
root
O administrador do sistema, com poder total. No Ubuntu, você usa esse poder via sudo. Veja: sudo.

S

Serviço
Programa gerenciado pelo systemd, que pode iniciar sozinho no boot. Veja: systemctl.
Shell
Programa que interpreta seus comandos. No Ubuntu, o bash. Veja: O Terminal.
Shell script
Arquivo de texto com comandos que rodam em sequência. Veja: Primeiro Script.
Sinal
Aviso enviado a um processo, como TERM ("termine") ou KILL ("pare agora"). Veja: Encerrar Programas (kill).
Sistema de arquivos
A forma como os dados são organizados num disco (ext4, btrfs, vfat…). Veja: Particionar e Formatar.
Snap
Formato de pacote da Canonical, com apps isolados e atualizações automáticas. Veja: Snap.
Snapshot
Fotografia de um volume ou dataset num momento, para voltar atrás depois (LVM, ZFS, LXD). Veja: ZFS.
SSH
Protocolo para acessar outra máquina pelo terminal, com criptografia. Veja: SSH.
SSID
O nome de uma rede Wi-Fi, o que aparece na lista. Veja: Wi-Fi.
stdin, stdout, stderr
As três vias de um comando: entrada (0), saída normal (1) e saída de erros (2). Veja: Redirecionamento.
sudo
Comando que executa outro como administrador, pedindo a sua senha. Veja: sudo.
Swap
Área do disco usada como memória extra quando a RAM enche. Veja: Particionar e Formatar.
SysRq
Teclas mágicas tratadas direto pelo kernel, úteis quando tudo trava (REISUB). Veja: Quando o Sistema Trava.
systemd
O primeiro programa a rodar no boot; inicia e vigia todos os serviços. Veja: systemctl.

T

Terminal
A janela onde você digita comandos para o shell. Veja: O Terminal.
Timer (systemd)
Agendamento feito pelo systemd, alternativa ao cron. Veja: Criar um Serviço.
TTY
Console de texto fora da interface gráfica, aberto com Ctrl+Alt+F3. Veja: Quando o Sistema Trava.

U

ufw
Uncomplicated Firewall: o jeito simples de configurar o firewall no Ubuntu. Veja: Firewall (ufw).
Unit
Qualquer coisa que o systemd gerencia: serviço, timer, socket, montagem. Veja: systemctl.
UUID
Identificador único de uma partição; não muda se o disco trocar de nome. Veja: lsblk, df, du.

V

Variável de ambiente
Valor guardado com nome (ex.: HOME, PATH) que os programas leem. Veja: .bashrc, alias, PATH.
VG (grupo de volumes)
No LVM, o "cofre" de espaço formado por um ou mais PVs, de onde saem os LVs. Veja: LVM.
VM (máquina virtual)
Computador simulado por software, com seu próprio sistema. Ótima para praticar sem risco. Veja: Instalação.
Volume (Docker)
Pasta guardada fora do container, para os dados sobreviverem quando ele é apagado. Veja: Docker.
VPN
Túnel criptografado que liga máquinas ou redes pela internet, como se estivessem na mesma rede. Veja: VPN (WireGuard).

W

Wayland
O sistema gráfico usado pelo Ubuntu 26.04 (substitui o antigo X11). Veja: O Desktop.
WireGuard
VPN moderna, simples e rápida, integrada ao kernel Linux. Veja: VPN (WireGuard).

Y

YAML
Formato de texto para configurações, baseado em indentação (Netplan, Docker Compose, Ansible, cloud-init). Veja: Configurar a Rede.

Z

ZFS
Sistema de arquivos e gerenciador de discos com snapshots, compressão e verificação de integridade. Veja: ZFS.
